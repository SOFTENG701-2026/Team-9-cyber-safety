# SOFTENG-701-Group-9-Project

## Setup:
Make a copy of .env.example and rename to .env

Ensure you have the latest version of Node and npm installed you can check with
```
npm -version
node -v
```

## Running React Front-End:

Open terminal in root directory (SOFTENG701-Group-9-Project):

Install dependencies
```
cd frontend
npm install
```

To run client:
```
npm run dev
```

## Running Node Back-End:

Open terminal in root directory (SOFTENG701-Group-9-Project):

Install dependencies
```
cd backend
npm install
```

To run server:
```
npm start
```

## Checking correctness
If everything is set up correctly you should see a page that reads:

"Message from backend: Hello World"
